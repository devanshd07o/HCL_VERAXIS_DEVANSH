# VERAXIS Interface Design System State

- **Palette**: Obsidian & Ionized Gold (Executive Luxury SaaS)
  - Dark Anchor Base: `#090B10` (Canvas), `#161B26` (Surface), `#1E2534` (Elevated Surface)
  - Light Symmetrical Base: `#F7F8FA` (Canvas), `#FFFFFF` (Surface), `#EEF1F6` (Elevated Surface)
  - Precision Accent: `#E3B341` (Ionized Champagne Gold — Dark), `#B47B0E` (Burnished Amber Gold — Light)
  - Typography Ink: `#F8FAFC` / `#8A99AD` (Dark), `#090B10` / `#475569` (Light)
- **Direction**: Precision & Sophistication
- **Primary Grid**: 4px base (`4/8/12/16/24/32/48px` strict rhythm)
- **Elevation & Depth**: 1px crisp borders (`rgba(248,250,252,0.08)` dark / `rgba(9,11,16,0.09)` light) paired with kinetic border trails / subtle metallic shine
- **Touch Targets**: `>= 44px` on mobile touch controls, `36px–40px` desktop density controls
- **Scroll Discipline**: Strict single-axis scrolling inside active reader (`no nested vertical scrollboxes`), floating scroll button cleared cleanly from prose
